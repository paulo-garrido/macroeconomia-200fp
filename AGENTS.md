# Macroeconomía 200 FP

Este repositorio administra el curso Macroeconomía 200 FP de la
Maestría en Formulación y Evaluación de Proyectos.

## Reglas generales

1. No modificar la estructura de evaluación sin autorización del docente.
2. Mantener todas las presentaciones y páginas en Quarto.
3. Conservar la identidad visual institucional del curso.
4. Antes de publicar el sitio:
   - ejecutar quarto render;
   - comprobar enlaces;
   - verificar recursos;
   - comprobar que no existan errores de RevealJS.
5. Nunca publicar información individual de estudiantes.

## Calificación

Las evaluaciones deben calificarse utilizando exclusivamente
la rúbrica correspondiente en evaluaciones/rubricas/.

Nunca modificar una nota sin indicar:
- estudiante;
- actividad;
- criterio;
- puntuación;
- justificación.

El resultado debe incluir:
- nota por criterio;
- nota total;
- comentario breve;
- aspectos a mejorar.

No penalizar aspectos que no estén contemplados en la rúbrica.

## Sitio web

Antes de modificar una sesión:
1. revisar sesiones anteriores;
2. conservar diseño y estructura;
3. verificar navegación;
4. ejecutar el sitio localmente;
5. reportar los archivos modificados.

Nunca hacer push directamente sin comprobar primero el render.
